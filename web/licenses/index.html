Audio import

Audio conversion uses a source-built FFmpeg 5.1.4 audio-only WebAssembly decoder and the ffmpeg.wasm wrapper. Audio stays on your computer.

Download decoder source and build scripts · Build instructions · Pinned inputs

FFmpeg LGPL 2.1 · LGPL 3 · FFmpeg license notes · Wrapper MIT notice · Emscripten notices

The source archive includes the configuration and changes used for this build. Rebuild and replace the paired ffmpeg-core.js and ffmpeg-core.wasm files under prepare-audio/vendor in a local copy of the site to use a modified decoder. Debugging modifications to these open-source components is not restricted by this notice.

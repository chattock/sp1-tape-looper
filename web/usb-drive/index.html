Hold T2 + T3. Open Finder.

Stop playback, finish saving, close control pages and stop USB audio. Hold T2 + T3 together for five seconds, then release. The SP-1 checks its storage and opens the drive. No browser connection or folder selection is needed.

Copy files using Imports/Exports. Eject in Finder when finished: the SP-1 checks storage and returns to Tape Looper automatically. Playback and recording pause during drive mode.

Connection check & diagnostics

This optional check only reads device status. It never mounts, formats or repairs a drive.

If all four track lights repeat a double blink, leave the device powered and save diagnostics. Do not reflash to bypass its recovery lock.

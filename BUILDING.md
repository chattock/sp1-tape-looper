# Building Tape Looper 4.0

The release image is 774,068 bytes, SHA-256 `e73e3786c1a2b33cf92685f92533404f5eec78f4f9384607725bf7c2140badbf`. It preserves storage and includes the tested Tone/Compression selector on the original updater baseline.

The checked-in source contains the controller dependency closure, original radio integration source and website source. Historical directory names are retained to preserve relative include paths. Only the three build entry points below are release firmware targets.

**This checkout is not a self-contained build of all release components.** Two original-updater inputs are excluded: `tools/clean608/radio/admission.h` (qualification tables) and `tools/clean608/radio/generated/ram_image.h` (vendor programming-helper payload). Vendor radio profiles/templates and SDK dependencies are also external. The local build was verified using those inputs; a clean-machine build without them is not claimed. Never replace them with empty stubs or private device backups. The planned Bluetooth SDK will provide a separate integration/build workflow.

## Reproduction prerequisites

Use the exact module commits in `release612-dependencies.json`, Zephyr SDK 0.17.4, CMake, Ninja, DTC and Zephyr's Python dependencies. Apply `patches/zephyr-uac2.patch` to the pinned Zephyr checkout. The patch is part of this build: it includes the USB audio full-speed Windows workaround. Point `ZEPHYR_BASE` and `ZEPHYR_SDK_INSTALL_DIR` to those installations. The successful local build used CMake 3.26.4, DTC 1.8.1 and west 1.5.0.

Set `src` to this checkout and `build_root` to a new empty directory. Supply the two original-updater inputs privately and change only the absolute SHA-header include in `admission.h` to the matching source in this checkout.

```sh
cmake -GNinja -S "$src/tools/capacity422/runtime" -B "$build_root/runtime" \
  -DBOARD=stem_player -DBOARD_ROOT="$src" \
  -DEXTRA_CONF_FILE="$src/tools/capacity422/runtime/bt/runtime/async.conf" \
  -DEXTRA_DTC_OVERLAY_FILE="$src/tools/capacity422/runtime/bt/runtime/usb-console.overlay"
cmake --build "$build_root/runtime" -j4
cmake -GNinja -S "$src/tools/maintenance425" -B "$build_root/maintenance" \
  -DBOARD=stem_player -DBOARD_ROOT="$src"
cmake --build "$build_root/maintenance" -j4
cmake -GNinja -S "$src/tools/clean608/radio" -B "$build_root/radio" \
  -DBOARD=stem_player -DBOARD_ROOT="$src"
cmake --build "$build_root/radio" -j4
python3 "$src/tools/package-release.py" \
  --runtime "$build_root/runtime/zephyr/zephyr.elf" \
  --maintenance "$build_root/maintenance/zephyr/zephyr.elf" \
  --radio "$build_root/radio/zephyr/zephyr.elf" \
  --dispatch "$src/tools/startup612/dispatch.S" \
  --toolchain-prefix "$ZEPHYR_SDK_INSTALL_DIR/arm-zephyr-eabi/bin/arm-zephyr-eabi-" \
  --output "$build_root/package"
```

The packager requires pyelftools. It validates flash placement and RAM usage, emits a report, and refuses to emit the release BIN if its complete hash differs. Use it instead of the historical package scripts that depend on older binaries. The local rebuild used pinned external checkouts plus the included patch; a clean-machine build is still unverified.

## Website

Serve `web/` over localhost or HTTPS. The source tree deliberately excludes compiled radio/controller payloads, decoder WASM and the source archive. The deployed site includes these separately. The release provides the controller BIN and matching decoder-source archive. The radio payload is not supplied by this source checkout. Do not expose a partially populated local Setup as a working installer.

Print guides are generated by `python3 docs/print-v4/build_guides.py` with ReportLab. Outputs are written to `output/pdf/`.
